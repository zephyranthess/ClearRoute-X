# ClearRoute X

Public pages for the ClearRoute X iPhone and iPad app, served with GitHub Pages:

- Home: https://zephyranthess.github.io/ClearRoute-X/
- Support: https://zephyranthess.github.io/ClearRoute-X/support.html
- Privacy Policy: https://zephyranthess.github.io/ClearRoute-X/privacy.html
- Terms of Use: https://zephyranthess.github.io/ClearRoute-X/terms.html

The HTML pages and the `.md` copies are generated from the app's own legal text (`lib/legal` in the app project, `dart run tool/build_legal.dart`), so the app and the website say the same thing.

`app_store_descriptions/` holds the App Store listing text.

Contact: support@norfa.fun
